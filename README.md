# TaskNebula AI

I'm thrilled (and humbled) to announce I built a to-do app. 🚀

But not just any to-do app. TaskNebula AI. A task board with:

🔥 a "0-day todo streak"
🕹 a task claw machine
🐬 a gacha arcade where you can pull an Executive Dolphin
📡 a "Meeting Séance" category
🎮 an arcade (Snake, Minesweeper, Sudoku and more, all "counted as inventory")
📺 fake sponsored ads for things like "Sumpbräu: all the flavor of shouting at a forklift"

Is it productive? No. Is it a 12-section, fully gamified, ad-supported, dolphin-integrated task management platform? Also no. But it's mine. 💪

Here's what I learned building it:

1️⃣ Scope creep is a feature. I set out to make a checklist. I now have a leaderboard.
2️⃣ Hosting doesn't have to be scary. I'm running it from my own machine and exposing it with a Cloudflare Tunnel. No server rental, no deploy pipeline, one command and it's live on the internet.
3️⃣ Dumb ideas ship faster than serious ones. Nobody expects a roadmap from a shrimp badge.
4️⃣ Fun is a valid product requirement.
